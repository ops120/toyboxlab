# 怪兽删除确认器

一个 Windows 小玩具：把要删除的文件拖到程序上，会弹出一个怪兽确认窗。

## 效果

1. 怪兽举着文件问：「oi，是这个吗？」
2. 两个按钮都是「是」——没有取消。
3. 点任意一个「是」：文件先进回收站，然后播放爆炸特效，怪兽朝右上角飞出屏幕，窗口关闭。

## 用法

### 方式一：直接运行 Python

```bash
python delete_monster.py "要删除的文件.txt"
```

### 方式二：拖放文件到 `运行.bat`

把要删除的文件拖到 `运行.bat` 上松手即可。

### 方式三：打包成 exe 后拖放

运行 `打包exe.bat`，得到 `dist\怪兽删除.exe`。之后把文件拖到 `怪兽删除.exe` 上即可。

## 测试模式

不加文件参数会进入演示模式，自动生成并删除一个临时文件。

加 `--auto-confirm` 可在无头/录屏环境下自动点确认，方便验证动画流程：

```bash
python delete_monster.py "测试文件.txt" --auto-confirm
```

## 素材

- `monster.webp`：怪兽图片（「想拆学校」梗图），打包时会一起打进 exe。
- 如果删掉 `monster.webp`，程序会自动回退到手绘版怪兽。

## 安全说明

- 文件会被移到**回收站**，不是永久删除，误删还能恢复。
- 两个按钮都是确认，没有取消——这就是玩具的整蛊点，别拿来删重要文件。
