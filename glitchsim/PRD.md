## 1. 产品概述

### 1.1 一句话描述
一个 Windows 小工具，启动后全屏模拟显卡"花屏/显示器故障"的视觉故障效果，用于整蛊、演示或趣味体验，按一个快捷键即可瞬间恢复。

### 1.2 背景与动机
屏幕花屏（画面出现彩色噪点、色块位移、撕裂、像素化等）通常让人第一反应是"显卡坏了/显示器坏了/电脑坏了"。
本项目用一个独立程序**逼真地复现**这种视觉效果，不触碰任何系统真实数据，用来：
- **整蛊**：骗朋友"我电脑花屏了"，再轻松恢复；
- **演示/教学**：讲解显卡故障、屏幕撕裂原理时的直观演示；
- **趣味体验**：喜欢复古 CRT / 故障艺术（Glitch Art）风格的人。

### 1.3 目标用户
- 普通用户（整蛊、猎奇）
- 售后/维修培训演示场景
- 数字艺术/故障艺术爱好者

### 1.4 核心原则
1. **必须能一键退出**——这是安全底线，绝不能让用户"卡死在花屏里"（详见 5.2）。
2. **纯视觉**、零入侵——绝不修改注册表、壁纸、文件或系统设置。
3. **逼真优先**——尽可能模拟真实花屏的故障感。

### 2.1 花屏故障模式（视觉效果）

> v0.2 变更：按用户澄清，「花屏」以**屏线（LVDS/eDP 排线）损坏的竖条纹**为主要形态，
> 新增模式 1 并设为默认；原 8 种顺延为 2~9，快捷键由 1~8 扩展为 1~9。

程序至少支持以下一种或多种，且可叠加随机切换：

1. **屏线竖条纹（Cable Fault，默认）**：屏线/排线接触不良式彩色竖线。特征：位置基本固定（坏的就是那几根）、全高贯穿、边缘锐利、成簇分布，轻微抖动、偶发闪烁与整屏闪白；底层桌面内容仍可辨认。
2. **彩噪/雪花（Static Noise）**：全屏随机彩色像素/噪点，类似老电视无信号或显存损坏。全屏或局部区域。
3. **色块位移（Block Shift）**：屏幕被切分成大小不一的矩形块，各块随机平移/错位，边缘生硬。
4. **像素化/马赛克（Pixelation）**：画面（或彩色背景）按大像素方块化，清晰度骤降。
5. **撕裂线/glitch 线（Tear Lines）**：多条水平的亮线/撕裂带快速上下跳动，类似垂直同步失效。
6. **RGB 通道偏移（Channel Shift）**：红/绿/蓝通道相互错位，产生重影/"色漏"效果。
7. **区域矩形错乱（Scrambled Regions）**：屏幕上若干矩形区域内容被复制/打乱/反复粘贴，像显存地址错乱。
8. **扫描线/抖动（Scanlines）**：细横线阵列覆盖，偏 CRT 质感。
9. **渐变故障（Gradient Corruption）**：颜色渐变出现条带/色带（banding），伴随抽动。

> 注：具体渲染基于程序自绘的随机色块/噪点，而非截取真实画面（见 5.1 边界）。
> 实现说明：低分辨率缓冲承载底图特效，竖条纹等需要"锐利细线"的元素在放大到全屏后以原生分辨率叠加，保证线宽为 1~8 物理像素。

## 3. 交互设计

### 3.1 启动流程
1. 双击 exe 启动。
2. 自动进入全屏（P0），可选短暂"预加载画面"（约 0.3s 纯色）防突兀。
3. 立即开始渲染花屏效果。

### 3.2 运行时交互
| 操作 | 结果 | 说明 |
|------|------|------|
| **退出键**（默认 `ESC`、`Ctrl+Alt+Q`，可配置） | 退出恢复 | 见 4.1 `exit_keys` |
| `+ / -` | 增大/减小强度 | 实时调整 |
| 托盘图标右键 | 暂停 / 退出 | 保底退出入口 |

> `Ctrl+Alt+Q` 为**硬编码终极兜底**，不随配置失效，防止用户配错键把自己锁死。

### 3.3 退出反馈
退出后不弹任何对话框，直接从当前状态回到桌面，保持用户设备零改动。

## 4. 配置项

以符合系统习惯的方式（可选：启动参数 / 配置文件 `config.ini` / 界面设置窗口）。

| 项 | 取值/范围 | 默认 | 说明 |
|--------|-----------|------|------|
| 强度 intensity | 0.1 ~ 1.0 | 0.6 | 竖线条数、故障区宽度、泛色区多少 |
| 帧率 | 30 / 60 / 120 | 60 | 渲染流畅度（竖线静止，30 也够） |
| 持续时间 | 0（无限）/ N 秒 | 0 | 自动恢复 |
| 启动延迟 delay | 0 ~ N 秒 | 0 | 启动后延迟多久才出现（开机自启场景） |
| 退出键 exit_keys | 键名/组合，逗号分隔 | `esc, ctrl+alt+q` | 见 4.1 |
| 托盘提示 hint | on / off | on | 气泡显示退出键 |

### 4.1 自定义退出键 `exit_keys`

- 语法：多个热键用逗号分隔，修饰键用 `+` 连接，修饰键支持 `ctrl` / `alt` / `shift` / `win`。
- 示例：`esc`、`f8`、`ctrl+shift+k`、`win+x, delete`。
- 可用键名：`esc` `space` `enter` `tab` `backspace` `insert` `delete` `home` `end`
  `pageup` `pagedown` `printscreen` `scrolllock` `pause`、方向键、字母 `a`~`z`、
  数字 `0`~`9`、`f1`~`f24`、标点符号键。
- 匹配规则：未配置修饰键的热键宽容匹配（只认主键，带修饰键按下也算）；
  配置了修饰键则要求这些修饰键**全部**处于按下状态。
- 无法识别的键名会在启动时告警并忽略。

### 4.2 开机启动 `autostart`

- **以 `config.ini` 为准**：`autostart = true / false`。程序每次启动都会把该值同步到系统
  （多了就建、少了就删，状态一致则不动），因此改 ini 即可，**无需额外命令**。
- 实现：在用户级「启动」文件夹（`CSIDL_STARTUP`）放置/删除一个 VBS 启动器
  （`wscript` 执行，无黑窗）。**不写注册表 Run 键**，用户可直接删除该文件撤销。
- 命令行 `--autostart on/off` 仍然保留：它除了设置系统状态，还会把结果写回 `config.ini`，
  避免 ini 与实际状态不一致（否则下次启动会被 ini 覆盖回去）。
- 只有 ini 里**显式出现** `autostart` 键时才做同步；没写则保持系统现状不动。
- 建议配合 `delay`（进桌面后延迟出现）或 `duration`（自动恢复）使用。

## 5. 安全与边界

### 5.1 明确不做
- **不截取、不保存、不上传真实屏幕内容**：v0.3 曾引入一次性桌面快照，v0.4 改为透明悬浮层后
  **已完全取消**，程序不再以任何方式采集屏幕画面。
- **不修改系统**：不改壁纸、注册表、hosts、启动项、文件。
- **不锁死系统**：任何时候 ESC/强退杀进程都能恢复。

### 5.2 必须退出（安全底线）
- 默认热键 `ESC` 与 `Ctrl+Alt+Q` 必须**始终生效**，即使花屏渲染出现异常也不能吞掉键盘事件。
- 程序异常退出时（如崩溃），绝不能导致光标消失或系统状态残留。
- 不允许设置"无法退出的花屏"（如吞掉 ESC 的彩蛋模式默认关闭）。

### 5.3 免责提示
首版可在启动时极短暂提示"按 ESC 退出"，降低整蛊对象恐慌（该提示默认开启，可配置关闭）。

## 7. 技术方案（建议）

| 方案 | 语言/栈 | 优点 | 缺点 | 推荐 |
|------|---------|------|------|------|
| A | C# + WinForms / WPF | 系统级窗口、热键好实现、打包 exe 方便、Win 生态好 | 需 .NET 运行时（可自包含发布） | ✅ 推荐 |
| B | C/C++ + Win32 + GDI/DirectX | 最底层、性能最好、体积最小 | 开发成本高，需手动处理窗口/热键 | 进阶 |
| C | Python + pygame | 开发最快 | 打包体积大（pyinstaller），性能一般 | 快速原型 |

> **推荐方案 A**：WPF/WinForms 全屏窗口 + 定时器按帧重绘随机色块/噪点，配合 `RegisterHotKey` 处理 ESC/强退，`Application.SetSuspendState`/关闭全屏窗口即可恢复。用 .NET 自包含发布生成单个 exe。

### 7.1 关键实现点（备忘）
- 全屏无边框窗口：`FormBorderStyle.None` + `WindowState=Maximized` / `TopMost`。
- 帧循环：`System.Windows.Forms.Timer` 或 `CompositionTarget.Rendering` 按帧重绘。
- 随机噪声：`Random` 生成像素色，用 `Bitmap`/`LockBits` 或 `WriteableBitmap` 快速填充。
- 热键：`RegisterHotKey` 注册 ESC/Ctrl+Alt+Q，或键盘钩子（注意别吞键盘）。
- 恢复：关闭全屏窗口，光标恢复可见，进程退出。

## 8. 验收标准（DoD）

- [ ] 启动后进入全屏，覆盖桌面。
- [ ] 至少 3 种故障模式渲染正常且可切换（P0 至少屏线竖条纹 + 彩噪 + 撕裂线）。
- [ ] 屏线竖条纹线宽为原生分辨率 1~8 物理像素，位置在一次运行内保持固定。
- [ ] 按 `ESC` 或 `Ctrl+Alt+Q` 立即恢复桌面，光标正常。
- [ ] 运行时 60 FPS，无明显卡顿。
- [ ] 杀进程后系统无任何残留改动。
- [ ] 全流程不写任何系统文件/注册表。
